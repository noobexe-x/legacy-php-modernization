# Legacy PHP Modernization

Modernization, infrastructure redesign, and cloud migration practice for a legacy Laravel/PHP project.

---

## Project Goals

- Analyze legacy Laravel/PHP architecture
- Modernize monolithic project structure
- Dockerize local development environment
- Deploy infrastructure using Terraform
- Practice AWS cloud migration
- Separate static and dynamic resources
- Improve maintainability and deployment workflow
