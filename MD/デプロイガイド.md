# デプロイ手順（AWS · Terraform + 手動アプリ）

- **リージョン:** `ap-northeast-1`。コンソールは右上で **東京** を選択（他リージョンでは EC2 が見えない）。
- **構成の要点:** `MD/技術メモ.md` を参照。

---

## 前提

- Terraform 1.5+、AWS CLI、認証情報（推奨: WSL2 Ubuntu）
- 本リポジトリ clone 済み

---

## インフラ作成

```bash
cd terraform
cp terraform.tfvars.example terraform.tfvars
# tfvars 編集（例: create_route53_record = false で ALB DNS のみ）
terraform init -input=false
terraform plan -input=false
terraform apply -input=false
```

- Route53 を使う場合: 事前にパブリックホストゾーンを作成し `domain_name` を設定。

---

## 出力（接続情報）

```bash
terraform output alb_dns_name
terraform output ec2_instance_id
terraform output rds_endpoint
terraform output rds_port
terraform output s3_bucket_id
terraform output -raw db_password
```

| 用途 | 内容 |
|------|------|
| HTTP 疎通 | `http://<alb_dns_name>/` |
| EC2 起動/SSM | `ec2_instance_id` |
| `.env` DB | `DB_HOST`=`rds_endpoint`、`DB_PORT`、`db_name`/`db_username` は tfvars に合わせる |
| DB パスワード | `terraform output -raw db_password`（リポジトリに含めない） |

---

## EC2 の起動・停止

```bash
aws ec2 start-instances --region ap-northeast-1 \
  --instance-ids "$(cd terraform && terraform output -raw ec2_instance_id)"

aws ec2 stop-instances --region ap-northeast-1 \
  --instance-ids "$(cd terraform && terraform output -raw ec2_instance_id)"
```

RDS / NAT / ALB は EC2 停止後も課金が残る。

---

## EC2 接続（Session Manager）

```bash
aws ssm start-session --region ap-northeast-1 \
  --target "$(cd terraform && terraform output -raw ec2_instance_id)"
```

## 初回 EC2 状態

- user data で **システム nginx** が **:80**、プレースホルダ HTML。
- ALB ターゲットはインスタンス **80**。

Laravel を載せる場合: システム nginx とポートが被るなら停止するか、`docker-compose.aws.yml` 等で **80** をコンテナに寄せる。手順は `技術メモ.md` の Docker 節と以下。

### Docker（RDS 利用）の概要

1. EC2 に Docker / Compose をインストール（AL2023 公式手順）。
2. 必要なら `sudo systemctl stop nginx && sudo systemctl disable nginx`。
3. コード配置、`/.env` に RDS・`APP_URL=http://<alb_dns>` 等。S3 利用時は EC2 ロールにバケット権限を付与するか `FILESYSTEM_DISK=local` で検証。
4. `docker compose -f docker-compose.aws.yml up -d --build`
5. `docker compose -f docker-compose.aws.yml exec php php artisan migrate --force`（必要なら `db:seed`）

## 確認

- ブラウザ: ALB DNS
- EC2: ターゲットグループ **healthy**
- CloudWatch: 東京リージョン、アラーム OK
- S3: `aws s3 ls s3://<bucket>/ --region ap-northeast-1`

---

## 削除

```bash
cd terraform
terraform destroy -input=false
```

RDS 削除保護が有効なら先に無効化。

---

## トラブルシュート

| 現象 | 確認 |
|------|------|
| コンソールに EC2 が無い | リージョンが東京か |
| 502/503 | ターゲットヘルス、:80 リッスン、SG |
| DB 接続不可 | `.env`、RDS は非公開のため VPC 内からのみ |
| SSM 不可 | インスタンスロール、NAT、エージェント |

ログ: `/var/log/user-data.log`、`docker compose ... logs`、`storage/logs/laravel.log`
